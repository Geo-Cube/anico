# Testovací plán US-06 – Detail nabídky

Odvozeno z [`anico-domain.md`](../anico-domain.md) §5 US-06, [ADR-0008](../adr/0008-nabidky-vnorene-ve-zvireti.md),
[návrhu UC-06](../design/uc-06-detail-nabidky.md) a plánu úkolu. Úrovně: **I** = HTTP + skutečná MongoDB
(`apps/animal-service/tests/integration/offers.test.ts`), **U** = unit (`tests/unit/offers.test.ts`, testy dokladů,
`tests/unit/openapi-document.test.ts`, `packages/shared-schemas/tests/offer.test.ts`). Identita je skutečně
podepsaný ES256 JWT ověřený `@anico/auth`. Ověřený chovatel je v integračních testech fake port; samotná
projekce `verifiedBreeders` je pokrytá stávajícími testy `verified-breeder`. Případy závislé na čase používají
vstřikované `now`. Stavy nabídek se zakládají přímým zápisem (`storeOffer`).

## 2. Nepokryto automaticky

- **Nasazení a ověření na devu:** detail není nasazený. Ruční scénáře proběhnou po nasazení podle
  [dev-testovani.md](dev-testovani.md).
- **Frontend:** není napojen (`AnimalOfferPage.tsx` je mock se snake_case poli); zobrazení detailu, hlášky pro 404
  a skládání URL fotek se netestují.
- **Výkon:** index `animals_offer_id` se ověřuje existencí a počtem dotazů, ne dobou odezvy nad velkým objemem.
- **Skutečné plynutí času:** přechody `SCHEDULED → ACTIVE → EXPIRED` se testují vstřikovaným `now`.
- **Přechod poptávek stažené nabídky na `EXPIRED`:** UC-07 jej zatím neprovádí (komentář `TODO` ve stažení nabídky);
  detail se stavem poptávky `EXPIRED` počítá jen jako se vstupem (UC06-INQ-5).
- **Vyhledávání a vyřízení poptávek (US-05, US-08–US-10):** neexistují.
